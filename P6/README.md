# Laporan Praktikum Basis Data 2

## Deskripsi
Project ini berisi laporan praktikum Basis Data 2 mengenai penerapan query SQL pada Sistem Informasi Puskesmas menggunakan database MariaDB/MySQL.

Database yang digunakan bernama `puskesmas_db` dan terdiri dari beberapa tabel seperti:
- pasien
- dokter
- petugas
- rekam_medis
- pemeriksaan
- pembayaran
- obat
- resep
- pendaftaran_pasien
- poli_puskesmas

## Materi Query yang Dibahas
Laporan ini membahas penggunaan beberapa query SQL, yaitu:
1. SELECT
2. COLUMN ALIAS (AS)
3. WHERE
4. ORDER BY
5. LIMIT dan OFFSET
6. TABEL JOIN
7. DISTINCT

## Tools yang Digunakan
- XAMPP
- MariaDB / MySQL
- phpMyAdmin
